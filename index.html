Conectar Excel desde OneDrive

Para conectar tu archivo de Excel institucional, necesitas registrar una aplicación en Azure Active Directory de PUCMM y proporcionar las credenciales aquí. Los datos se guardan solo en tu navegador.

Client ID (Azure App Registration)
En portal.azure.com → App Registrations → tu app → Application (client) ID
Tenant ID (Tu organización PUCMM)
En portal.azure.com → Azure Active Directory → Tenant ID
Ruta del archivo en OneDrive
Ruta relativa desde la raíz de tu OneDrive personal institucional
API Key de Claude (para el chat con IA)
Obtén tu clave en console.anthropic.com → API Keys. Se guarda localmente en tu navegador.
